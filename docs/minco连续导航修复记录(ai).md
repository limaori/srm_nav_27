# MINCO 连续导航第一阶段修复记录

日期：2026-10-08。

本轮落实“修复停走原因、区分局部末端类型、3 米规划视野”。保持最高平移速度
1.5 m/s、加速度上限 3.0 m/s²、MINCO 权重、MPC 权重及控制频率不变。

## 已实施

### 1. 动态障碍从观测中消失后，主代价地图仍残留障碍

`IntensityVoxelLayer` 每帧 `resetMaps()`，但原来只上报当前障碍点和车身 footprint
的更新范围。当点云缩小、障碍消失或图层禁用时，上一帧范围之外的主地图单元不会
重新合成，可能长期残留 lethal 障碍。此问题同时影响全局和局部地图。

修复为：每帧将本层上一帧和当前帧的世界坐标更新范围一并提交，由 LayeredCostmap
重新合成该区域。没有降低障碍阈值、关闭地形图层或改变静态地图。另为体素成员提供
默认值，避免基类初始化调用虚函数 `matchSize()` 时使用尚未加载的体素高度。

新增四个实际 LayeredCostmap 集成用例：障碍消失、障碍移动到别处、滚动原点变化、
图层禁用。修复前四个用例均复现旧单元保持 254；修复后全部通过。

### 2. 局部截取与末端速度

- 用最近线段投影替代“最近路点 + 1”，保留车辆前方尚未经过的拐角。
- 按不大于半格的间距检查整个连接段和视野插值段；停止于不可通行或地图边界之前。
- 地图范围检查保留车身净空；地图外、未知或障碍不会被作为可穿越捷径。
- 区分 `global_goal`、`planning_horizon`、`map_boundary`、`blocked`、`path_end`。
- 仅 `planning_horizon` 可保留末速；必须额外验证沿路径的延伸，以及沿末端切线的
  制动走廊。距离使用 `v * reaction_latency + v² / (2 * braking_deceleration)`，
  再增加一格距离，并确认全局路径尚有足够剩余长度。
- 仿真巡航末速设为 0.8 m/s；最终目标、地图边缘、障碍截断以及无安全制动延伸的
  视野末端仍然停车。末速同时受速度上限与前端可达速度限制。
- 用 `terminal_requires_stop` 区分“局部必须停车”和“已经到全局目标”，让 MPC 对
  地图/障碍边界同样生成停车参考，而不把这种停车误报为导航成功。
- 诊断增加 `terminal_reason`、`terminal_speed`；成功规划也保留实际局部折线用于可视化。

### 3. 短停车轨迹与碰撞验证

原校验器将总时长不足 0.6 秒的轨迹一律判为覆盖不足，包括已经可安全停车的短终点
轨迹。现在仅当轨迹明确要求停车、末端速度和加速度接近零、实际轨迹时长覆盖当前
速度对应的制动时间时，允许用已验证终点的静止参考补足 MPC 预测窗口。

运动中的末端和制动时间不足的轨迹不享有此补足。全段碰撞、动态约束、地图和轨迹
时效检查保持有效。同时修复原碰撞采样在时长不是采样周期整数倍时遗漏最后一点的问题。

### 4. 仿真参数

文件：`src/srm27_navigation/srm27_nav_bringup/config/simulation/nav2_params_srm_minco.yaml`。

| 参数 | 原值 | 本轮值 |

| `FollowPath.planning_horizon` | 2.0 m | 3.0 m |

## 尚未消除的现象

第二次试跑入口附近仍存在全局无路径和局部起点被判 `blocked` 的短暂情况，不能将
本轮描述成“零恢复”或“已完全根治坡面障碍误判”。地图快照显示部分动态障碍出现在
静态图空闲区；是否为坡面分类、实时几何或点云配准问题，需要用同时刻原始/地形点云
进一步区分。本轮修复了已由代码及测试证实的残留机制，没有凭猜测放宽碰撞阈值。
